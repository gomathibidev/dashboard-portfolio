Investment Dashboard

Interactive Power BI dashboard designed to track stock portfolio performance across multiple reporting dates. The solution provides comprehensive investment analysis through dynamic KPIs, return comparisons, dividend tracking, portfolio monitoring and company-level drill-through insights. Interactive buttons allow users to seamlessly switch between Absolute Returns and XIRR analysis across key report visuals. Report-wide date slicers enable easy comparison between current and previous portfolio performance.
